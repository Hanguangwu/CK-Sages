# 孔子年表

| 聖元紀年 | 主要事件                                                     | 魯國紀年       | 西曆紀年    |
| -------- | ------------------------------------------------------------ | -------------- | ----------- |
| 聖元1年  | 孔子生。                                                     | 魯襄公二十一年 | 西元前552年 |
| 聖元4年  | 孔子年三歲。父叔梁紇卒。                                     | 魯襄公二十四年 | —           |
| 聖元18年 | 孔子年十七歲。母顏徵在卒，卒年在此之前。                     | 魯昭公七年     | —           |
| 聖元20年 | 孔子年十九歲。娶宋亓官氏。                                   | 魯昭公九年     | —           |
| 聖元21年 | 孔子年二十歲。生子鯉，字伯魚。                               | 魯昭公十年     | —           |
| 聖元28年 | 孔子年二十七歲。郯子來朝，孔子見之，向其學習古代官制與官名。孔子任魯國委吏、乘田，當在此事之前。 | 魯昭公十七年   | —           |
| 聖元31年 | 孔子年三十歲。孔子初入魯太廟，當在此之前。琴張從遊，約在此時或稍早。孔子至此開始授徒設教，顏無繇、仲由、曾點、冉伯牛、閔損、冉求、仲弓、顏回、高柴、公西赤等人先後從學。 | 魯昭公二十年   | —           |
| 聖元35年 | 孔子年三十四歲。魯國孟僖子卒，遺命其二子孟懿子及南宮敬叔師事孔子，學習禮制。二子當時年十三歲，正式從學可能在此後。 | 魯昭公二十四年 | —           |
| 聖元36年 | 孔子年三十五歲。魯國三家共攻魯昭公，昭公奔齊。孔子亦於此年赴齊，在齊聞《韶》樂。齊景公曾向孔子問政。 | 魯昭公二十五年 | —           |
| 聖元37年 | 孔子年三十六歲。孔子當於此年返回魯國。                       | 魯昭公二十六年 | —           |
| 聖元38年 | 孔子年三十七歲。吳國季札赴齊後返國，其長子卒，葬於嬴、博之間。孔子自魯前往觀摩其葬禮。 | 魯昭公二十七年 | —           |
| 聖元48年 | 孔子年四十七歲。魯國陽貨執季桓子，陽貨欲見孔子，當在此事之後。 | 魯定公五年     | —           |
| 聖元51年 | 孔子年五十歲。魯國三家攻陽貨，陽貨奔陽關。同年，公山弗擾召孔子。 | 魯定公八年     | —           |
| 聖元52年 | 孔子年五十一歲。魯國陽貨奔齊。                               | 魯定公九年     | —           |
| 聖元52年 | 孔子開始出仕，任魯國中都宰。                                 | 魯定公九年     | —           |
| 聖元53年 | 孔子年五十二歲。由中都宰升任司空，後任大司寇。以相禮之職輔佐魯定公與齊侯會於夾谷。 | 魯定公十年     | —           |
| 聖元55年 | 孔子年五十四歲。魯國採納孔子墮三都之議，先後試圖拆毀郈、費、成三城，最終未能完成，墮三都之議遂告停頓。 | 魯定公十二年   | —           |
| 聖元56年 | 孔子年五十五歲。離開魯國，前往衛國。衛人端木賜從學。         | 魯定公十三年   | —           |
| 聖元57年 | 孔子年五十六歲。離衛途中經過匡地。晉國佛肸來召，孔子欲往而未果，後再返衛國。 | 魯定公十四年   | —           |
| 聖元58年 | 孔子年五十七歲。始見衛靈公，出仕衛國，並見衛靈公夫人南子。   | 魯定公十五年   | —           |
| 聖元59年 | 孔子年五十八歲。衛靈公曾向孔子問陳，或在此年，或在次年。孔子辭去衛國官職，離衛之時可能在次年。 | 魯哀公元年     | —           |
| 聖元60年 | 孔子年五十九歲。衛靈公卒，孔子離衛之時可能在其卒前，也可能在其卒後。 | 魯哀公二年     | —           |
| 聖元61年 | 孔子年六十歲。由衛赴曹，再赴宋。宋國司馬桓魋欲殺孔子，孔子改裝離去，前往陳國，後在陳國出仕。 | 魯哀公三年     | —           |
| 聖元64年 | 孔子年六十三歲。吳國攻陳，孔子離陳，在陳、蔡之間絕糧，後赴蔡，見楚國葉公；又由葉返回陳，再由陳返回衛。 | 魯哀公六年     | —           |
| 聖元65年 | 孔子年六十四歲。再次在衛國出仕，時為衛出公四年。             | 魯哀公七年     | —           |
| 聖元69年 | 孔子年六十八歲。魯國季康子召孔子，孔子返回魯國。自離魯赴衛至重返魯國，前後約十四年。此後進入晚年講學時期，有若、曾參、言偃、卜商、顓孫師等人先後從學。 | 魯哀公十一年   | —           |
| 聖元70年 | 孔子年六十九歲。子孔鯉卒。                                   | 魯哀公十二年   | —           |
| 聖元72年 | 孔子年七十一歲。顏回卒。齊國陳恒弒其君，孔子請求魯國出兵討伐，魯國君臣未予採納。同年，魯國西狩獲麟，孔子作《春秋》至此絕筆。《春秋》始筆之年不可考。 | 魯哀公十四年   | —           |
| 聖元73年 | 孔子年七十二歲。仲由死於衛國。                               | 魯哀公十五年   | —           |
| 聖元74年 | 孔子年七十三歲，卒。                                         | 魯哀公十六年   | 西元前479年 |
